## Read this first

1. **A bug in my A2-2 prep code would have corrupted Tier 1.** `make_scenario()`
   read `args$Delta`, and `$` on a list partial-matches `Delta_std`. Any
   nonzero `Delta_std` was silently divided by `s_ref` (effect about 0). The prep
   only ever used `Delta_std = 0`, so it never showed. Caught by a smoke test
   (the grid showed `Delta_std` values of 83,333). Fixed with `args[["Delta"]]`
   in `simulations/R/scenarios.R`. Nothing from before today with nonzero
   `Delta_std` is valid; the A2-1 pilot used legacy `Delta=` inputs and is
   unaffected.
2. **"Mixed model beats two-stage" is mostly not supported.** For balanced
   G >= 3 the LMM and two-stage ANOVA gave the same rejection decision in all
   but 1 of 9,600 paired comparisons (24 cells x 200 datasets; the one
   discordance is at G=4, n=5, Delta_std 0.5, LMM only). For G = 2 the two
   differ only at n <= 3, and only because the two-stage arm uses Welch's t (small
   Welch df) while the LMM uses a pooled variance. Details and a proposal below.
3. **Slope-only LMM is confirmed badly anti-conservative.** Cautionary comparator
   stays labeled.

| 2 | 0.025 | 0.065 | 0.050 | 0.035 |

Mean 0.052. Under the Q7 rule only G = 2, n = 2 is "controlled" (CP upper 0.057);
the rest are "neither" (upper bounds 0.084 to 0.109 at R = 200), no cell
"liberal". R = 200 cannot do better; Tier 2 is where Q7 gets decided. The
singular rate falls with size (G=2: 0.54, 0.22, 0.04, 0 at n = 2, 3, 5, 10);
0 failures.

**Primary LMM power, Delta_std = 1.0, n = 5, G = 2: 0.975 (CP 0.94 to 0.99).**
Caveat for the lead sentence: this is at cv = 1/3 (Delta/tau = 3); at cv = 2/3 it
is 0.525 and at L = 50 kb 0.595. Power at Delta_std = 0.5 is 0.54. At n = 2,
G = 2: 0.17, 0.37, 0.69 for Delta_std 0.5, 1, 1.5 (M2 confirmed in practice).

**Slope-only LMM (CAUTIONARY).** Type I 0.45 to 0.90 across all 12 cells, rising
with G (G=2 about 0.45 to 0.53, G=4 0.76 to 0.90). Prep finding confirmed at
scale; not a recommended approach.

**KW chi-square at n = 3, G = 2: chance, not systematic.** 0.150 in these 200
(CP 0.10 to 0.21), but replicates 1 to 60 are the same datasets the prep used,
so the two numbers were not independent. A fresh 3,000 datasets (replicate IDs
2001 to 5000, slopes only) gave **0.098 (0.088 to 0.109)**, matching the 0.10
hand calculation (M4). At G = 3, 4 (n = 3) it is conservative (0.005, 0.020).
It cannot reject at n = 2.

**KW permutation.** Omnibus Type I at or below 0.055 in every cell (max 0.055 at
G=3, n=10 and G=4, n=5). At G = 2 it is 0 at n = 2 and 3 (minimum p = 0.10), so
it has **zero power at G = 2, n = 3** (LMM 0.74 at Delta_std = 1). Two things to
know: Dunn-ungated under this arm is *not* exact (normal approximation), giving 0.150
at G = 2, n = 3; and the gate is exact, so Dunn-gated is 0.000 there.
`kw_perm_method`: `exact_enum` for G=2 (n <= 10), G=3 (n <= 4), G=4 (n = 2);
`random_perm` otherwise. The prep log's "G=2, n >= 9 is not exact" was wrong: the
boundary is G=2, n >= 11 (C(20,10) = 184,756 <= 2e5).

**Two-stage vs primary LMM (paired).**
- G >= 3, balanced: identical except that one dataset (G=4, n=5, Delta_std 0.5).
- G = 2, n = 2: Type I 0.005 vs LMM 0.025; power at Delta_std 0.5/1/1.5:
  0.08/0.16/0.36 vs 0.18/0.37/0.69 (paired diff +0.10/+0.21/+0.33, CIs exclude 0).
- G = 2, n = 3: power 0.22/0.65/0.93 vs 0.31/0.74/0.97 (+0.09, +0.09, +0.04).
- G = 2, n >= 5: no difference.

I think the LMM advantage at G = 2 comes from the pooled-variance t (equal to ANOVA F
on the slopes) versus Welch, not from the mixed model, because for balanced
designs the mixed-model F on the interaction should reduce to the ANOVA on
per-sample slopes, and the G >= 3 results are near-exact ties. The proposal is a sixth
arm, pooled-variance two-stage (`t.test(var.equal = TRUE)` at G = 2), cheap
(about 0.01 s). If it ties the LMM at G = 2, the paper's claim should be "the LMM
matches the classical ANOVA on slopes under balance and beats KW", and a real
mixed-model advantage can only show up in the unbalanced or heteroscedastic
families (PLAN 4.1, S3), which should be moved up in priority. This is a
methodological point about the benchmark spec (Q2), so it is a memo-style
request, not something I changed.

**Paired LMM vs KW (positive = LMM rejects more).**
- n = 3, G = 2: chi-square KW rejects more (Delta_std 0.5/1/1.5: -0.17/-0.13/
  -0.02), but the gain is from the chi-square approximation's inflated Type I
  (about 0.10 true), so it is not a power advantage. Permutation KW: LMM +0.31/
  +0.74/+0.97 (KW cannot reject).
- n = 3, G = 3: LMM +0.21/+0.69/+0.78 against both KW omnibus variants (KW
  chi-square 0.005 Type I, power 0.18 at Delta_std 1, versus LMM 0.87).
- n = 5, G = 2: LMM +0.04 (chi-square, CI +0.003 to +0.077) and +0.11 (permutation)
  at Delta_std 0.5; at Delta_std >= 1 within about 0.02 (ceiling).
- n = 5, G = 3: LMM +0.10 (chi-square), +0.07 (permutation) at Delta_std 0.5.

**Collapse hypothesis:** yes. Power agrees across `s_ref` (3e-6, 6e-6, 1.2e-5)
within CI at n = 3 (0.765/0.74/0.77) and n = 5 (0.98/0.975/0.985), and across `cv`
at matched Delta_std/cv = 3 (n=3: 0.78/0.74/0.785; n=5: 0.99/0.975/1.00); one
comparison, n = 5 and cv = 2/3 (+0.025, CI 0.001 to 0.057), sits at the ceiling and
is borderline.

**M3 (anchor position):** still inconclusive. Primary LMM Type I pooled over n = 3, 5
(400 per anchor): 0.055, 0.080, 0.0575, 0.0525, 0.055 for anchor 0.1, 0.25, 0.5, 0.75, 0.9
(homogeneity p = 0.49). The one liberal cell is anchor 0.25, n = 5: 21/200 = 0.105
(CP 0.066 to 0.156); the other four anchors at n = 5 are all exactly 10/200. No
trend toward the ends. p-values across anchors are uncorrelated, so these are
independent draws, and one of ten cells out of 100+ comparisons is not strong evidence;
the same size of excess appears at s_ref = 1.2e-5, n = 5 (0.095). Worth a
dedicated R = 5,000 anchor Type I cell in Tier 2.
